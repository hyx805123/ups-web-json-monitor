# UPS 监控台 · 最简版（回退备用）

这是**回退专用**的最小可用版本。完整版在同级目录 `../upsmon/`。

| | 完整版 `upsmon/` | 最简版 `upsmon-v1-minimal/` |
|---|---|---|
| 采集 + 看板 | ✅ | ✅ |
| 设备增删 | ✅ | ✅（仅增删，无编辑） |
| 设备字段（场地/上线日期/服务商） | ✅ | ❌ |
| 分组（型号/场地/状态/自定义） | ✅ | ❌ |
| 配置模板 | ✅ | ❌ |
| 告警规则 + 企微/邮件推送 | ✅ | ❌ |
| 历史永久落盘 + 折线图 | ✅ | ❌（仅内存 4 小时） |
| 身份认证 | 预留（见文档） | ❌ |

## 何时回退

完整版出现异常、且你只想让监控先跑起来时，用这个版本。

## 怎么回退

```bat
:: 1) 停掉完整版
:: 2) 启动最简版
cd /d "C:\Users\apps\Desktop\AI coding\UPS\upsmon-v1-minimal"
start.bat
```

两个版本默认端口都是 8686，**不能同时启动**。
若想两个并存（例如同时对比），给最简版换个端口：

```bat
set PORT=8687
start.bat
```

## 数据互不干扰

两个版本各有独立的 `data/` 目录：

* `upsmon/data/devices.json` —— 完整版的设备清单
* `upsmon-v1-minimal/data/devices.json` —— 最简版的设备清单（**首次启动是空的，需要重新录入**）

最简版**不会**读取完整版的历史数据，回退后历史曲线会从零开始。

## 建议

完整版稳定运行一段时间（至少覆盖一次断网恢复、一次告警推送）后，
再把这套最简版当成真正的"兜底"，平时不用碰。
