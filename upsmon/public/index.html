身份认证与权限管理

当前状态：未启用。本系统部署在内网，看板与 API 暂不鉴权。
已完成的预留设计见 docs/AUTH-DESIGN.md，要点：
1. 账号体系：本地账号 + 预留 AD/LDAP、CAS 对接
2. 角色模型：超级管理员 / 运维工程师 / 只读观察者 / 审计员
3. 权限矩阵：按「看板只读、配置可写、告警可配、设备可增删改、凭据不可见」五类操作切分
4. 会话与审计：HttpOnly Session、登录审计、操作留痕、密码策略
5. 凭据保护：设备密码、企微 webhook、SMTP 口令分角色可见，API 永不回传明文

如需现在就上，可按最小可用版实现：单管理员账号 + 登录页 + 会话 Cookie + 全部写操作鉴权。
